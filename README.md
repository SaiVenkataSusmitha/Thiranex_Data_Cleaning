
# Data Cleaning and Visualization Project

## Introduction
This project uses Python to clean, analyze,
and visualize student examination data.

## Objectives
- Inspect the dataset
- Identify missing values
- Find and remove duplicate records
- Generate statistical summaries
- Create visualizations
- Save the cleaned dataset

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Workflow
1. Load the CSV dataset.
2. Inspect rows, columns, and data types.
3. Check missing values and duplicates.
4. Remove duplicate rows.
5. Fill missing numerical values with their means.
6. Calculate descriptive statistics.
7. Generate histograms and a correlation heatmap.
8. Export the cleaned dataset and graphs.

## Files
- data_cleaning.py: Python source code
- StudentsPerformance.csv: Original dataset
- cleaned_data.csv: Cleaned dataset
- data_visualization.png: Histograms
- correlation_heatmap.png: Correlation heatmap

## How to Run
Install the required libraries:

pip install pandas matplotlib seaborn

Run the program:

python data_cleaning.py

## Conclusion
This project demonstrates basic data cleaning,
statistical analysis, and visualization using Python.
